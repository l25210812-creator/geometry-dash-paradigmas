    La Unidad 1 en nuestro código

    Nuestro juego en C# con raylib parte del programa que armamos en clase. Estos fragmentos muestran dónde aparece cada paradigma.

    Orientado a objetos

    Abstracción

    La clase abstracta Objeto define qué debe saber hacer cualquier cosa del juego, sin decir cómo.

    abstract class Objeto : IComparable<Objeto>
{
    public abstract void Draw();
    public abstract void Update(int w, int h);
    public abstract bool CollisionWith(Objeto o);
}
    Orientado a objetos

    Herencia y sobrescritura

    Jugador y Obstaculo heredan de Caja y cada uno redefine Update() a su manera.

    class Jugador : Caja
{
    public override void Update(int w, int h)
    {
        velocidad.Y += 0.8f;   // gravedad
        posición.Y  += velocidad.Y;
    }
}
    Orientado a objetos

    Polimorfismo

    Un solo ciclo actualiza y dibuja la lista sin preguntar qué tipo de objeto es cada elemento.

    List<Objeto> objetos = new();

foreach (var o in objetos)
    o.Update(screenWidth, screenHeight);

foreach (var o in objetos)
    o.Draw();
    Imperativo

    El ciclo del juego

    Instrucciones en orden que cambian el estado 60 veces por segundo: actualizar, revisar choques, dibujar.

    while (!Raylib.WindowShouldClose())
{
    if (!muerto) { /* actualizar */ puntos++; }
    Raylib.BeginDrawing();
    /* dibujar */
    Raylib.EndDrawing();
}
    Dirigido por eventos

    Responder al teclado

    El juego reacciona cuando el jugador presiona una tecla: saltar o reiniciar la partida.

    if (enSuelo && Raylib.IsKeyDown(KeyboardKey.Space))
{
    velocidad.Y = -15f;
    enSuelo = false;
}

    Procedural

    Una función recorre el arreglo y mueve los datos.

    static void ActualizarObstaculos()
{
  for (int i = 0; i < NUM_OBSTACULOS; i++)
  {
    obstaculos[i].x += obstaculos[i].vx;
    if (obstaculos[i].x + obstaculos[i].ancho < 0)
      obstaculos[i].x += DISTANCIA_REAPARICION;
  }
}

    Procedural

    Una función externa compara dos estructuras.

    static bool HayColision(Bloque a, Bloque b)
{
  return a.x < b.x + b.ancho &&
         a.x + a.ancho > b.x &&
         a.y < b.y + b.alto  &&
         a.y + a.alto > b.y;
}
